# Missions (OneDayReward) support

The missions themselves are data: `gameserver/data/OneDayReward.xml`, generated by
`tools/missions/gen_missions.py` of the server repository (see `tools/missions/MISSIONS.md`
there). The core's mission system (`OneDayRewardSystem = True` in `config/events.properties`)
tracks kills, raids, PvP, Olympiad, quests, fishing, enchanting, login, level, clan,
Noblesse and Hero on its own; the extension only adds what the core cannot express.

**Class transfer quest missions** (`com.l2horizon.CustomQuestsExt.missions.ClassQuestMissions`).
No core requirement can name a specific quest, so a mission that rewards a class transfer
quest carries a `<class_quests>401-418</class_quests>` element (quest ids and ranges, `;`
separated) that the core parser ignores. Its requirement is a `complete_quest` with an
impossible level condition, so ordinary quests never advance it. The extension reads the
element at load, listens to the core's `onQuestFinish` event, and when a listed quest ends
as completed (the quest state is kept as COMPLETED; an abandoned or repeatable exit removes
it and does not count) it sets the mission to done and refreshes the mission window. The
three missions map 401-418 (Path to ...), 211-233 (Trial, Testimony, Test of ...) and
70-100 (Saga of ...).

The class transfer missions themselves need no code: they are `obtain_level` missions
restricted by `classIds` to the classes of that tier and above (level 20 as a second class,
40 as a third, 76 as a fourth), so they complete with the transfer whatever way it was done.
